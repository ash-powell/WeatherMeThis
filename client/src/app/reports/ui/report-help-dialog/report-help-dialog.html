Moving Average

A moving average smooths short-term fluctuations so longer-term trends are easier to see.

It can only be used when group-by is Exact date, Month of each year, and Year.

WeatherMeThis first calculates each chart point using the selected aggregation and Group-by. It then averages consecutive chart points using the selected window size.

Moving average applies only to the current series. Add matching series with different window sizes—or leave one series unchanged—to compare them on the same chart.
